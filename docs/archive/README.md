이 디렉터리는 P0 1차 MVP 완료 시점의 문서 스냅샷이다. 원본 경로와 내용은 Git 태그 [`v0.1.0`](https://github.com/bamsongi-club/albam-mate/tree/v0.1.0)으로 고정한다.

- [P0 문서 묶음](p0/README.md)

## P1 2차 MVP (v0.2.0)

P1 필수 기능의 계약·생산 코드·자동 검증은 완료했고, 상시 운영 배포와 일부 실측이 남은 상태를 `completed-with-operational-limitations`로 동결했다. 검색·알림의 임시 AWS 검증 배포와 ROOM 로컬 기준선은 배포·실측 축을 분리해 보존한다.

- [P1 문서 묶음](p1/README.md)
- 원본 경로와 내용은 Git 태그 [`v0.2.0`](https://github.com/bamsongi-club/albam-mate/tree/v0.2.0)으로 고정한다.

P0·P1 문서는 종료 시점 사실관계와 링크 오류를 바로잡는 경우 외에는 수정하지 않는다. API와 ERD는 현재 계약의 정본으로 계속 `docs/`에 유지한다. 현재 단계의 범위와 구현 기준은 [P2 명세](../P2-spec.md)와 [P2 기능 문서](../p2/README.md)에서 관리한다.
