# 문서 아카이브

## P0 1차 MVP (v0.1.0)

이 디렉터리는 P0 1차 MVP 완료 시점의 문서 스냅샷이다. 원본 경로와 내용은 Git 태그 [`v0.1.0`](https://github.com/bamsongi-club/albam-mate/tree/v0.1.0)으로 고정한다.

- [P0 문서 묶음](p0/README.md)

P0 문서는 수정하지 않는다. API와 ERD는 현재 계약의 정본으로 계속 `docs/`에 유지한다. 다음 단계의 범위와 구현 기준은 P1 명세가 작성된 뒤 현재 문서 영역에서 관리하고, 완료된 단계만 이 아카이브에 같은 구조로 보관한다.
