# 알밤메이트 PRD

- 버전: v1.2
- 최종 수정일: 2026-07-23
- 문서 상태: **전체 제품 목표와 단계별 범위 정의**


> 이 문서는 알밤메이트가 궁극적으로 제공할 제품 경험을 정의한다. P0는 이 목표를 향한 **1차 MVP 배포 범위**이며, P0 15개 API와 P0 데이터 계약을 먼저 구현한다. P0 범위와 전체 목표를 같은 것으로 취급하지 않는다.

> P0 구현 계약은 [P0-spec](P0-spec.md), [ERD](ERD.md), [API](API.md)에서 관리한다.

## 1. 배경과 문제

보드게임을 하고 싶은 사용자는 원하는 시간에 함께할 사람, 할 게임, 규칙 설명 가능 여부를 한 번에 맞추기 어렵다. 모집 글마다 게임·시간·장소·인원·진행 정보가 흩어져 있어, 실제 플레이까지 이어지지 못하는 경우가 많다.

특히 초보·라이트 유저는 다음 장벽을 느낀다.

- 함께 갈 일행이 없거나 시간·장소를 맞추기 어렵다.
- 어떤 게임을 골라야 할지, 자신에게 너무 어렵지는 않을지 판단하기 어렵다.
- 규칙을 설명하거나 진행해 줄 사람이 있는지 알기 어렵다.

알밤메이트의 전체 목표는 신규 가입자 수가 아니라 **게임·참가자·진행 정보가 맞는 실제 모임이 성립하고 완료되는 비율**을 높이는 것이다.

## 2. 제품 비전과 경계

### 제품 비전

알밤메이트는 사용자가 게임 또는 사람을 기준으로 모임을 찾고 만들며, 필요하면 룰마스터의 진행 정보와 신뢰 이력을 참고해 실제 오프라인·온라인 플레이까지 이어 갈 수 있는 보드게임 세션 플랫폼이다.

### 장기 제품 목표

1. 사용자가 게임명, 인원, 시간, 복잡도, 테마·메커니즘 등으로 자신에게 맞는 게임과 세션을 찾는다.
2. 사용자가 게임 중심 또는 사람 중심 모임을 만들고, 다른 사용자가 조건을 확인한 뒤 안전하게 참여한다.
3. 룰마스터의 진행 가능 게임·이력·후기를 참고해 초보도 참여 판단을 할 수 있다.
4. 온라인 세션에서는 현재 `ACTIVE` 참가자 전용 조율 공간과 외부 플레이 플랫폼 연결로 실제 플레이를 지원한다.
5. 완료·참석·후기 데이터가 다음 모임의 신뢰와 선택을 돕는다.

### 제품 경계

- P0의 모임 참가는 무료다. 포인트 충전·지급·차감·반환 방식의 참여 정책은 후속 후보이지만, 도입 여부·금액·노쇼 처리 기준은 아직 정하지 않는다. 감사비·보드게임 판매·주문·배송은 제품 범위에 넣지 않는다.
- 인앱 보드게임 엔진, 음성·화상 통화는 제공하지 않는다. 온라인 플레이는 외부 플랫폼 연동과 조율 도구에 집중한다.
- 공개 정보는 참여 판단에 필요한 범위로 제한하며, 이메일·인증 정보는 다른 사용자에게 노출하지 않는다.
- P0는 홍대 지역 오프라인 모임으로 한정한다. 장소 검색·필터는 제공하지 않으며, 세션 상세에 텍스트로 장소를 표기하는 수준으로 충분하다. 지역 확장은 P0 검증 뒤 후속 후보로 논의한다.

## 3. 사용자와 역할

### 참가자

게임 또는 사람을 기준으로 모임을 탐색하고, 시간·장소·모집 인원·진행 정보를 확인한 뒤 참가하는 사용자다.

### 주최자

세션을 만들고 수정·취소·종료하는 사용자다. 참가자 표시에는 포함되지만, `participations` 참가 관계로 중복 저장하지 않는다.

### 룰마스터

P0에서는 별도 계정이나 자격 상태가 아니다. 주최자가 세션의 `isRulemasterLed`를 `true`로 설정하면 그 세션에서 규칙 설명·진행을 맡겠다는 자기신고다.

P0에서는 이 자기신고 값을 별도로 검증하지 않는다. 초기 사용자 규모에서는 신고 오남용보다 진입 장벽을 낮추는 것이 우선이며, 후속 이력·후기 기반 신뢰 시스템이 이 문제를 자연스럽게 보완할 것으로 본다.

후속 단계에서는 사용자가 진행 가능 게임, 초보자 진행 가능 여부, 설명 언어·시간 등을 등록하고 완료 이력·후기를 쌓는 룰마스터 프로필을 제공할 수 있다. 다만 이 등록은 `isRulemasterLed`를 설정하는 선행 조건이나 권한 게이트가 아니다.

## 4. 전체 제품 경험

### P0: 세션 성립 경험

~~~text
게임명 또는 세션 제목으로 모임 탐색
→ 시간·장소·모집 인원·경험 수준·룰마스터 진행 여부 확인
→ 선착순 참가
→ 모집 인원 충족 또는 시작 시각 도달 시 자동 모집 완료
→ 필요 시 참가 취소 또는 주최자 취소·종료
~~~

### 후속 확장 경험 (도입 차수 미정)

~~~text
조건 검색으로 게임·세션·룰마스터 후보 탐색
→ 진행 가능 게임·후기·이력 확인
→ 오프라인 또는 온라인 세션 참여
→ 온라인이면 현재 `ACTIVE` 참가자 전용 조율 공간과 외부 플랫폼 접속
→ 플레이 완료·후기·참석 이력 반영
→ 다음 모임 선택에 신뢰 정보 활용
~~~

## 5. 기능 요구사항

### P0 1차 MVP

- **P0-01 · 계정과 본인 프로필:** 회원가입·로그인·닉네임 기준의 본인 프로필 조회·수정을 제공한다.
- **P0-02 · 게임 조회:** 세션 생성용 읽기 전용 게임 목록·상세(영문명, 별칭, 이미지, 권장 인원, 게임 태그, 예상 시간, 복잡도, 간단 설명, 상세 설명, 계산된 예정 모임 수)와 게임명 키워드 조회를 제공한다.
- **P0-03 · 게임·사람 중심 세션:** 게임 중심과 사람 중심 세션을 모두 생성·조회·수정·취소·종료할 수 있다. 주최자 외 활성 참가자가 있으면 수정할 수 없다.
- **P0-04 · 키워드 검색:** 게임명으로 게임을 검색해 선택한 게임의 세션 목록을 보고, 사람 중심 세션은 세션 제목으로 목록을 검색한다.
- **P0-05 · 선착순 참가 정합성:** 일반적인 순차 요청에서 중복 참가와 모집 인원 초과를 막고, 참가·취소에 따라 모집 상태를 자동 전이한다. 다수 동시 요청의 잠금·트랜잭션 보장은 후속 정책이다.
- **P0-06 · 내 모임:** `role` 기준 참여·개설 모임 조회와 세션 상세의 참가자 목록을 제공한다.
- **P0-07 · 세션 단위 룰마스터 진행:** 누구나 `isRulemasterLed`를 자기신고해 세션에 표시할 수 있다.

### 후속 기능 후보 (도입 차수 미정)

- **조건 검색:** 인원, 예상 시간, 난이도, 지역, 경험 수준, 스타일 태그, 카테고리·BGG Weight로 게임과 세션을 찾는다.
- **사람 중심 조건 보강:** 사람 중심 세션은 게임 없이도 유지하며, 원하는 태그·카테고리·난이도는 선택 정보로 저장·검색할 수 있다. 필수 조건으로 강제하지 않는다.
- **룰마스터 프로필:** 룰마스터 모드 ON/OFF, 진행 가능 게임, 초보자 진행 정보, 이력·후기 표시를 제공한다.
- **후기와 신뢰:** 완료된 세션의 `ACTIVE` 참가 이력이 있는 사용자가 후기를 작성·수정·삭제하고, 참석·취소·진행 이력을 신뢰 정보로 활용한다.
- **탐색 보조:** 인기 게임, 실시간 인기 검색어, 오늘 바로 참여 가능한 모임을 제공한다.
- **온라인 세션:** 온라인 모임을 만들고, 현재 `ACTIVE` 참가자만 접속 정보와 조율 공간에 접근하게 한다.
- **플레이룸·채팅:** 모집 인원 충족 뒤 전용 플레이룸·텍스트 채팅을 활성화하고, 외부 플랫폼 링크를 안전하게 공유한다.
- **게임 정보 보강:** AI 핵심 규칙 요약, 규칙 설명 영상 연결을 제공한다.
- **추천:** 유사 게임 추천과 개인화 추천 알고리즘을 검토한다.
- **내 후기:** 내가 작성한 후기 목록을 조회한다.
- **운영·안전:** 사용자 신고·차단, 노쇼 신고와 이의제기 흐름을 제공한다.
- **포인트 정책:** 포인트 충전, 가입 보너스, 세션 생성·참가 차감, 세션 종료 뒤 반환을 검토한다. 기준 금액 `1,000`과 노쇼 미반환은 정책 후보일 뿐 확정 규칙이 아니다.
- **알림:** 세션·참가·후기 등 주요 이벤트 알림을 제공한다.
- **프로필 이미지:** 공개 프로필 이미지 등록·변경을 제공한다.

## 6. 공통 비즈니스 규칙

### 세션 유형

| 유형 | 게임 | 태그·카테고리·BGG Weight | P0 검색 |
|---|---|---|---|
| `GAME_FOCUSED` | 게임 목록의 게임 1개 필수 | 게임의 단일 태그는 표시하고, 조건 검색은 제공하지 않음 | 선택 게임명 |
| `PERSON_FOCUSED` | 선택 사항 | 모두 선택 사항이며 필수 조건이 아님 | 세션 제목 |

P0의 게임 `tag`는 카탈로그 표시값이며, 세션 검색 필터나 사람 중심 세션의 선택 조건이 아니다.

### 모집 인원과 상태

- 모집 인원 API 필드 `recruitmentCapacity`는 DB의 `sessions.capacity`에 저장하는 주최자 제외 정원이다. 총 모임 인원은 모집 인원에 1을 더한 값이다.
- P0의 `region`은 `홍대`로 고정하고, 실제 모임 장소는 `place`로 저장·표시한다. 지역 입력·필터는 제공하지 않는다.
- 주최자는 세션의 개설자이며, 참가자 표시에는 포함하되 `participations` 참가 관계 행으로 중복 저장하지 않는다.
- 남은 모집 자리는 `capacity - activeParticipationCount`로 계산하며, `participantCount`는 주최자 1명과 활성 참가 관계 수의 합이다.
- 주최자 외 `ACTIVE` 참가자 수가 모집 인원에 도달하거나 시작 시각에 도달하면 `RECRUITING → CLOSED`가 자동으로 일어난다.
- 시작 시각 전 참가 취소로 빈자리가 생기면 `CLOSED → RECRUITING`이 자동으로 일어난다.
- 상태값은 `RECRUITING`, `CLOSED`, `CANCELED`, `FINISHED`다. `CANCELED`, `FINISHED`는 최종 상태다.
- 공개 세션 목록에는 `RECRUITING`, `CLOSED`만 보이며, `CANCELED`, `FINISHED`는 본인 내 모임 이력과 직접 상세 조회에서만 확인한다.
- 시작 시각으로부터 24시간이 지난 `CLOSED` 세션은 자동으로 `FINISHED`가 된다. 주최자는 모임 후 `CLOSED` 세션을 직접 `FINISHED`로 처리할 수도 있다.
- 수동 모집 마감·재오픈은 제공하지 않는다. 취소는 물리 삭제가 아니라 `CANCELED` 상태 변경이다.
- 시간대가 겹치는 서로 다른 세션의 참가를 차단하지 않는다. 다수 동시 요청에서의 정원 보장 방식은 P0 이후 정책으로 둔다.

### 권한과 개인정보

- 세션 목록·상세·게임 목록·게임 상세는 비로그인 조회를 허용한다.
- 세션 수정·취소·종료는 주최자만 수행한다.
- 주최자 외 `ACTIVE` 참가자가 한 명 이상인 세션은 수정할 수 없다.
- 참가 취소는 본인만 수행하며, 주최자는 자신의 참가만 따로 취소하지 않고 세션 전체를 취소한다.
- 이메일·비밀번호 해시·인증 정보는 공개 응답에 포함하지 않는다.

## 7. 단계별 로드맵

| 단계 | 검증 질문·도입 상태 | 포함 범위 |
|---|---|---|
| **P0 1차 MVP** | 게임 또는 사람을 기준으로 만든 오프라인 모임이 안전하게 성립하는가? | 15개 API, 키워드 검색, 세션 CRUD, 선착순 참가·취소, 자동 상태 전이, 세션 단위 룰마스터 자기신고 |
| **후속 후보: 탐색·신뢰** | 도입 차수 미정 | 조건 검색, 태그·카테고리·BGG Weight, 후기, 인기 항목, 룰마스터 프로필·가능 게임 |
| **후속 후보: 온라인** | 도입 차수 미정 | 온라인 세션, 플레이룸·채팅, 외부 플랫폼 접속 정보 |

P0에서 후속 후보의 모델과 API를 미리 구현하지 않는다. 후속 후보의 도입 순서·차수는 P0 검증 뒤 결정하며, 그 후보가 존재한다는 사실이 P0 범위를 축소하거나 정책을 바꾸는 근거가 되지 않는다.

- 후속 후보: 온라인 플레이룸·채팅·외부 플랫폼 접근

## 9. 품질과 운영 요구사항

- 일반적인 순차 요청에서 모집 인원을 초과 배정하거나 같은 사용자를 중복 참가 처리하지 않는다. 다수 동시 요청의 경쟁 조건은 P0 이후 정책으로 관리한다.
- 참가·취소·상태 변경과 남은 모집 자리가 일관되게 계산된다.
- 후속 온라인 기능의 접근 정보와 채팅은 현재 `ACTIVE` 참가자에게만 제공한다.
- 후기·참석·룰마스터 신뢰 정보는 역할과 근거를 분리해 저장하고, 공개 기준을 운영 정책으로 문서화한다.
- 인기·검색 지표는 충분한 표본과 산출 기준을 함께 고려한다.

## 10. 성공 지표

| 목표 | 지표 |
|---|---|
| P0 모임 성립 | 세션 생성부터 모집 인원 충족까지 걸린 시간, 모집 인원 충족률 |
| P0 정합성 | 모집 인원 초과 차단 건수, 중복 참가 차단 건수, 상태 전이 오류 건수 |
| 탐색 전환 | 검색에서 세션 상세·참가로 이어지는 비율 |
| 모임 품질 | 참석률, 취소율, 후기, 재참여율 |
| 룰마스터 신뢰 | 룰마스터 진행 세션 수, 후기 수, 재참가율 |
| 온라인 전환 | 온라인 세션의 모집 인원 충족률, 플레이룸 활성화율 |

초기에는 P0 흐름의 기준선을 수집하고, 후속 후보의 지표는 실제 도입 범위를 정한 뒤 목표 수치를 정한다.
