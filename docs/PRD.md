# 알밤메이트 PRD

- 버전: v1.2
- 최종 수정일: 2026-07-23
- 문서 상태: **전체 제품 목표와 단계별 범위 정의**


> 이 문서는 알밤메이트가 궁극적으로 제공할 제품 경험을 정의한다. P0는 이 목표를 향한 **1차 MVP 배포 범위**다. P0 범위와 전체 목표를 같은 것으로 취급하지 않는다.

> P0 1차 MVP의 정본은 [P0-spec](P0-spec.md)이다. P0의 범위·사용 흐름·도메인·운영 규칙·완료 기준은 해당 문서에서 확인할 수 있다. 이 PRD는 제품 비전, 후속 후보와 측정 지표를 관리하며, P0 관련 내용이 다르면 P0-spec을 따른다. 데이터 모델과 요청·응답의 상세 계약은 [ERD](ERD.md), [API](API.md)에서 확인할 수 있다.

## 1. 배경과 문제

보드게임을 하고 싶은 사용자는 원하는 시간에 함께할 사람, 할 게임, 규칙 설명 가능 여부를 한 번에 맞추기 어렵다. 모집 글마다 게임·시간·장소·인원·진행 정보가 흩어져 있어, 실제 플레이까지 이어지지 못하는 경우가 많다.

특히 초보·라이트 유저는 다음 장벽을 느낀다.

- 함께 갈 일행이 없거나 시간·장소를 맞추기 어렵다.
- 어떤 게임을 골라야 할지, 자신에게 너무 어렵지는 않을지 판단하기 어렵다.
- 규칙을 설명하거나 진행해 줄 사람이 있는지 알기 어렵다.

알밤메이트의 전체 목표는 신규 가입자 수가 아니라 **게임·참가자·진행 정보가 맞는 실제 모임이 성립하고 완료되는 비율**을 높이는 것이다.

## 2. 제품 비전과 경계

### 제품 비전

알밤메이트는 사용자가 게임 또는 사람을 기준으로 모임을 찾고 만들며, 필요하면 룰마스터의 진행 정보와 신뢰 이력을 참고해 실제 오프라인·온라인 플레이까지 이어 갈 수 있는 보드게임 세션 플랫폼이다.

### 장기 제품 목표

1. 사용자가 게임명, 인원, 시간, 복잡도, 테마·메커니즘 등으로 자신에게 맞는 게임과 세션을 찾는다.
2. 사용자가 게임 중심 또는 사람 중심 모임을 만들고, 다른 사용자가 조건을 확인한 뒤 안전하게 참여한다.
3. 룰마스터의 진행 가능 게임·이력·후기를 참고해 초보도 참여 판단을 할 수 있다.
4. 온라인 세션에서는 현재 `ACTIVE` 참가자 전용 조율 공간과 외부 플레이 플랫폼 연결로 실제 플레이를 지원한다.
5. 완료·참석·후기 데이터가 다음 모임의 신뢰와 선택을 돕는다.

### 제품 경계

- 포인트 충전·지급·차감·반환 방식의 참여 정책은 후속 후보이지만, 도입 여부·금액·노쇼 처리 기준은 아직 정하지 않는다. 감사비·보드게임 판매·주문·배송은 제품 범위에 넣지 않는다.
- 인앱 보드게임 엔진, 음성·화상 통화는 제공하지 않는다. 온라인 플레이는 외부 플랫폼 연동과 조율 도구에 집중한다.
- 공개 정보는 참여 판단에 필요한 범위로 제한하며, 이메일·인증 정보는 다른 사용자에게 노출하지 않는다.
- 초기 오프라인 검증의 지역·장소 정책은 [P0-spec](P0-spec.md)에서 확인할 수 있다. 지역 확장은 초기 검증 뒤 후속 후보로 논의한다.

## 3. 사용자와 역할

### 참가자

게임 또는 사람을 기준으로 모임을 탐색하고, 모임 정보를 확인한 뒤 참가하는 사용자다.

### 주최자

세션을 만들고 모임 운영에 필요한 변경·취소·종료를 담당하는 사용자다.

### 룰마스터

룰마스터는 세션에서 규칙 설명과 게임 진행을 돕는 사용자다. P0의 룰마스터 표시와 권한 정책은 [P0-spec](P0-spec.md)에서 확인할 수 있다.

후속 단계에서는 사용자가 진행 가능 게임, 초보자 진행 가능 여부, 설명 언어·시간 등을 등록하고 완료 이력·후기를 쌓는 룰마스터 프로필을 제공할 수 있다.

## 4. 전체 제품 경험

### P0: 세션 성립 경험

P0 사용자 흐름과 화면 표시 기준은 [P0-spec](P0-spec.md)에서 확인할 수 있다.

### 후속 확장 경험 (도입 차수 미정)

~~~text
조건 검색으로 게임·세션·룰마스터 후보 탐색
→ 진행 가능 게임·후기·이력 확인
→ 오프라인 또는 온라인 세션 참여
→ 온라인이면 현재 `ACTIVE` 참가자 전용 조율 공간과 외부 플랫폼 접속
→ 플레이 완료·후기·참석 이력 반영
→ 다음 모임 선택에 신뢰 정보 활용
~~~

## 5. 기능 요구사항

### P0 1차 MVP

P0의 포함·제외 범위, API 목록과 구현 완료 기준은 [P0-spec](P0-spec.md)에서 확인할 수 있다.

### 후속 기능 후보 (도입 차수 미정)

- **조건 검색:** 인원, 예상 시간, 난이도, 지역, 경험 수준, 스타일 태그, 카테고리·BGG Weight로 게임과 세션을 찾는다.
- **사람 중심 조건 보강:** 사람 중심 세션은 게임 없이도 유지하며, 원하는 태그·카테고리·난이도는 선택 정보로 저장·검색할 수 있다. 필수 조건으로 강제하지 않는다.
- **룰마스터 프로필:** 룰마스터 모드 ON/OFF, 진행 가능 게임, 초보자 진행 정보, 이력·후기 표시를 제공한다.
- **후기와 신뢰:** 완료된 세션의 `ACTIVE` 참가 이력이 있는 사용자가 후기를 작성·수정·삭제하고, 참석·취소·진행 이력을 신뢰 정보로 활용한다.
- **탐색 보조:** 인기 게임, 실시간 인기 검색어, 오늘 바로 참여 가능한 모임을 제공한다.
- **온라인 세션:** 온라인 모임을 만들고, 현재 `ACTIVE` 참가자만 접속 정보와 조율 공간에 접근하게 한다.
- **플레이룸·채팅:** 모집 인원 충족 뒤 전용 플레이룸·텍스트 채팅을 활성화하고, 외부 플랫폼 링크를 안전하게 공유한다.
- **게임 정보 보강:** AI 핵심 규칙 요약, 규칙 설명 영상 연결을 제공한다.
- **추천:** 유사 게임 추천과 개인화 추천 알고리즘을 검토한다.
- **내 후기:** 내가 작성한 후기 목록을 조회한다.
- **운영·안전:** 사용자 신고·차단, 노쇼 신고와 이의제기 흐름을 제공한다.
- **포인트 정책:** 포인트 충전, 가입 보너스, 세션 생성·참가 차감, 세션 종료 뒤 반환을 검토한다. 기준 금액 `1,000`과 노쇼 미반환은 정책 후보일 뿐 확정 규칙이 아니다.
- **알림:** 세션·참가·후기 등 주요 이벤트 알림을 제공한다.
- **프로필 이미지:** 공개 프로필 이미지 등록·변경을 제공한다.

## 6. 단계별 로드맵

| 단계 | 검증 질문·도입 상태 | 포함 범위 |
|---|---|---|
| **P0 1차 MVP** | 게임 또는 사람을 기준으로 만든 오프라인 모임이 안전하게 성립하는가? | [P0-spec](P0-spec.md) 참조 |
| **후속 후보: 탐색·신뢰** | 도입 차수 미정 | 조건 검색, 태그·카테고리·BGG Weight, 후기, 인기 항목, 룰마스터 프로필·가능 게임 |
| **후속 후보: 온라인** | 도입 차수 미정 | 온라인 세션, 플레이룸·채팅, 외부 플랫폼 접속 정보 |

후속 후보의 도입 순서·차수는 P0 검증 뒤 결정한다.

## 7. 후속 화면과 정보 구조

- 후속 후보: 조건 필터, 룰마스터 프로필·가능 게임, 후기, 인기 탐색
- 후속 후보: 온라인 플레이룸·채팅·외부 플랫폼 접근

## 8. 품질과 운영 요구사항

- 후속 온라인 기능의 접근 정보와 채팅은 현재 `ACTIVE` 참가자에게만 제공한다.
- 후기·참석·룰마스터 신뢰 정보는 역할과 근거를 분리해 저장하고, 공개 기준을 운영 정책으로 문서화한다.
- 인기·검색 지표는 충분한 표본과 산출 기준을 함께 고려한다.

## 9. 성공 지표

| 목표 | 지표 |
|---|---|
| P0 모임 성립 | 세션 생성부터 모집 인원 충족까지 걸린 시간, 모집 인원 충족률 |
| P0 정합성 | 모집 인원 초과 차단 건수, 중복 참가 차단 건수, 상태 전이 오류 건수 |
| 탐색 전환 | 검색에서 세션 상세·참가로 이어지는 비율 |
| 모임 품질 | 참석률, 취소율, 후기, 재참여율 |
| 룰마스터 신뢰 | 룰마스터 진행 세션 수, 후기 수, 재참가율 |
| 온라인 전환 | 온라인 세션의 모집 인원 충족률, 플레이룸 활성화율 |

초기에는 P0 흐름의 기준선을 수집하고, 후속 후보의 지표는 실제 도입 범위를 정한 뒤 목표 수치를 정한다.
