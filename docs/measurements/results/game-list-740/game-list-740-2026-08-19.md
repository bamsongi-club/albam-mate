## 실행 조건과 batch 선택

- `albam-mate-771` 전용 Compose의 PostgreSQL·Redis·Spring 2개 인스턴스·proxy를 현재 image로 한 번 기동한 뒤 batch 1~3을 순차 실행했습니다. 세 batch 사이에는 서버를 재시작하지 않았습니다.

- PostgreSQL statement logging과 구조화 console logging은 batch 후 기본 요청 capture에만 임시로 켰고 원복했습니다. capture용 Spring 재시작은 batch 1~3의 수치에 포함하지 않습니다.
- 안전성 보강 전 2026-08-18 artifact는 응답·provenance guard 이전 결과라 최신 완료 근거에서 제외합니다. 이번 세 batch의 p95 편차도 한 개의 빠른 결과를 대표값으로 과장하지 않는 이유입니다.
