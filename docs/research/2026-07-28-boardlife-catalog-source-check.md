# 보드라이프 게임 카탈로그 운영 방식 공개 근거 점검

- 조사일: 2026-07-28
- 범위: 보드라이프 공개 게임 페이지, 데이터 등록 가이드, 정책·약관, 공개 프런트엔드 요청
- 한계: 내부 DB, 데이터 수집 작업, BGG와의 계약·허가 문서는 공개적으로 확인하지 못함

## 결론

보드라이프는 공개 화면에서 BGG API 응답을 그대로 중계하기보다 **자체 게임 ID와 자체 DB·백엔드 화면을 운영하고, 사용자 제안과 운영팀 검수로 데이터를 보완하면서 각 게임에 BGG 항목 링크를 연결하는 구조**로 확인된다. 다만 BGG와 유사한 메타데이터와 번역에 가까운 소개 문구가 있어도, 그 최초 취득 경로와 라이선스는 공개 자료만으로 알 수 없다. 따라서 보드라이프의 존재는 Albam Mate가 BGG 데이터를 무허가로 번역·재가공해도 된다는 근거가 아니다.

## 공개적으로 확인된 사실

### 1. 자체 식별자와 자체 서비스 데이터를 사용한다

[큐윅스 게임 페이지](https://boardlife.co.kr/game/2063/links)는 보드라이프 내부 경로 `/game/2063`을 사용하면서 BGG의 별도 항목 `131260`으로 연결한다. 같은 페이지에서 보드라이프 도메인에 저장된 이미지, 보드라이프 이용자 평점·순위, 한국어 제목과 게임 정보를 표시한다. 즉 보드라이프 ID와 BGG ID를 동일하게 쓰는 단순 프록시는 아니다.

공개 프런트엔드 스크립트도 설명 제안과 추천 인원 등의 요청을 `/game_data_ajax.php`, `/game_pop_ajax.php`, `/game_ajax.php` 같은 보드라이프 내부 경로로 전송한다. 이는 보드라이프 자체 백엔드에서 데이터를 읽고 수정하는 구조라는 증거이며, 외부 개발자에게 공개된 범용 API가 있다는 뜻은 아니다.

### 2. 사용자 등록과 운영팀 검수를 결합한다

[게임정보 데이터 페이지](https://boardlife.co.kr/record)는 사용자가 게임 데이터를 추가·수정하는 기능과 대기·완료·반려 상태를 제공한다. [게임 등록 가이드](https://boardlife.co.kr/game_edit.php?mode=guide)는 다음 절차를 명시한다.

- 새 게임은 한글명·영문명으로 등록하고 즉시 검색할 수 있다.
- 기존 게임 수정, 한국어판 예정 정보, 선주문·펀딩, 커버·배경 사진은 운영팀 검수를 거친다.
- 한국어판 예정·선주문·펀딩 정보에는 공식 링크를 요구한다.
- 커버·배경은 사용자가 업로드한 사진 중에서 신청할 수 있다.

따라서 카탈로그 전체가 한 외부 API에서 자동 동기화된다고 보기보다 커뮤니티 기여와 운영자 큐레이션이 실제 운영 축이다.

### 3. BGG 항목을 출처·참조 링크처럼 연결한다

확인한 게임 페이지들은 게임명, 연도, 인원, 시간, 난이도, 제작자·출판사 등의 정보를 자체 화면에 표시하고 해당 BGG 게임 페이지로 이동하는 링크를 함께 둔다. 샘플 페이지의 HTML과 공개 프런트엔드 스크립트에서는 BGG XML API를 브라우저가 직접 호출하는 정황을 찾지 못했다. 다만 서버가 과거 또는 배치 작업으로 BGG 데이터를 취득했는지는 이 사실만으로 판단할 수 없다.

### 4. 일부 한국어 소개는 BGG 문구와 매우 가깝다

보드라이프 [아크 노바 페이지](https://boardlife.co.kr/game/14832)는 짧은 소개로 `보존 프로젝트를 지원하는 현대적이고 과학적인 동물원을 설계하고 건설하세요.`라고 표시한다. BGG [아크 노바 페이지](https://boardgamegeek.com/boardgame/342942/ark-nova/expansions)의 영문 한 줄 소개는 같은 내용과 문장 구조를 가진다. 이는 번역 또는 공통 원문 사용 가능성을 보여 주지만, 누가 번역했는지와 어떤 허가를 받았는지는 증명하지 않는다.

## 권리·사업 운영에서 확인되는 사실

- [커뮤니티 규칙](https://boardlife.co.kr/policy.php)은 무단 발췌를 금지하고, 번역물에는 원작자 허가 여부를 확인·명시하며, 이미지도 공식 제공 자료인지 확인하도록 요구한다.
- [서비스 이용약관](https://boardlife.co.kr/policy.php?page=service)은 회원 게시물 저작권을 작성자에게 두고, 보드라이프가 검색·서비스 노출 등에 필요한 범위에서 이용할 수 있도록 정한다.
- 사이트에는 사업자 정보와 광고센터가 공개되어 있고 약관에는 유료서비스 조항도 있다. 따라서 공개 자료상 단순한 비영리 학생 프로젝트와 동일한 운영 형태라고 볼 수 없다.

## 확인되지 않은 사항

- BGG XML API·CSV·웹페이지·출판사 자료 중 무엇으로 초기 카탈로그를 구축했는지
- BGG와 표준 또는 별도 상업 라이선스 계약을 체결했는지
- BGG 유사 필드를 자동 수집하는지, 사람이 입력하는지, 두 방식을 혼합하는지
- 각 번역문·설명·이미지의 구체적인 원저작자와 허가 범위

샘플 페이지에서 `Powered by BGG` 로고를 찾지 못했다는 사실도 무허가 이용의 증거가 아니다. 별도 계약은 표준 XML API 조건과 다른 표시 조건을 정할 수 있기 때문이다.

## Albam Mate에 적용할 점

보드라이프에서 참고할 수 있는 것은 **구조**다.

1. `albam_game_id`와 `bgg_id`를 분리한다.
2. 원천 필드, 팀 작성 필드, 사용자 제안 필드의 출처를 따로 기록한다.
3. 사용자 수정 제안은 승인 큐를 거쳐 반영한다.
4. Albam Mate 평점·모임 데이터는 자체 데이터로 운영한다.
5. BGG에서 취득한 번역·요약·정규화 데이터는 BGG의 명시적 회신 범위 안에서만 공개한다.

자체 DB와 자체 API는 좋은 제품 구조이지만 원천 데이터의 이용 조건을 없애 주지는 않는다. Albam Mate가 독립적으로 조사한 객관적 사실과 처음부터 작성한 한국어 설명은 BGG 파생 데이터와 분리해 관리해야 한다.
