## 맥락

어떤 문제와 제약 때문에 결정이 필요한지, 무엇을 중요하게 판단했는지(판단 기준)를 적는다.

## 검토한 대안

각 대안을 같은 판단 기준으로 비교한다. 확인된 사실과 추정·가정을 구분하고, 무엇을 왜 골랐는지는 "결정"에 적는다.

| 대안 | 장점 | 비용·위험 | 판단 |
| --- | --- | --- | --- |
| 대안 A |  |  | 선택 |
| 대안 B |  |  | 제외 |

## 결정

무엇을 선택했는지와 결정적 이유를 적는다. 대안 비교를 되풀이하지 않는다.

## 결과

결정 이후 따라오는 효과를 적는다. 결정을 다시 정당화하지 않는다.

## 참고 자료
