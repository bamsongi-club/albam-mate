# ADR-0025: 게임 카탈로그 출처를 전역 푸터와 공개 출처 페이지에 표시

- 상태: 승인됨
- 작성일: 2026-07-30
- 결정일: 2026-07-31
- 관련: [GitHub Issue #221](https://github.com/bamsongi-club/albam-mate/issues/221), [GAME-03 게임 카탈로그 출처 표시](../../p0/game-catalog.md#game-03-게임-카탈로그-출처-표시), [ADR-0015](0015-bgg-baseline-team-collected-game-list.md), [ADR-0019](0019-bgg-full-catalog-staged-enrichment.md), [출처 manifest](../../game-catalog/2026-07-24-source-manifest.draft.json)
- 대체 대상: 없음
- 후속 ADR: 없음

## 맥락

Albam Mate P0의 2,000개 게임 카탈로그는 하나의 BGG 기준 스냅샷과 팀 수집 자료를 결합하고 팀이 검수한 결과다. 현재 출처 manifest는 `bgg_id`, 영문명과 Geekdo 이미지 URL처럼 BGG에서 온 값뿐 아니라 팀이 가공하거나 직접 작성한 표시명·별칭·태그·설명 등을 필드별로 구분한다. 이후 한국어명 보강에도 국내 공식 자료, 커뮤니티 카탈로그와 팀의 직접 검수·경험이 함께 들어갈 수 있다.

BGG는 순위 CSV를 XML API 라이선스 범위에 포함하며, 공개 앱에서 BGG를 데이터 출처로 표시하고 연결된 `Powered by BGG` 로고를 읽을 수 있는 크기로 노출하도록 요구한다. 또한 비상업적 이용만 허가하고 XML API로 받은 데이터의 수정을 금지하며, 팀이 보관한 승인 메일도 추가 번역·요약을 별도로 허용하지 않는다. 현재 프런트엔드에는 이 출처 표기와 공통 푸터가 없다.

모든 게임 정보를 BGG 단일 출처라고 표시하면 팀이 직접 작성·검수하거나 플레이 경험으로 판단한 값을 설명하지 못한다. 반대로 각 게임 카드와 상세 화면에 모든 출처를 반복하면 화면이 복잡해지고 출처 정보의 갱신 지점도 분산된다. 이용약관은 제3자 콘텐츠의 권리와 서비스 이용 규칙을, 개인정보처리방침은 개인정보 처리 목적·항목·보유 기간을 설명하는 문서이므로 게임 카탈로그의 상세 출처 목록을 대신하지 않는다.

이번 결정은 다음 기준을 만족해야 한다.

- BGG가 요구하는 공개 출처 표시를 모든 화면에서 일관되게 제공할 것
- 외부 원천, 팀 검수와 팀 직접 작성·경험을 서로 다른 기여로 설명할 것
- 상세 출처를 확인할 수 있으면서 게임 카드와 상세 화면의 정보 밀도를 높이지 않을 것
- 공개 안내와 내부의 게임별·필드별 provenance를 분리하되 서로 모순되지 않을 것
- 현재 2,000개 범위와 이미지 직접 참조 방식을 바꾸지 않을 것

## 검토한 대안

| 대안 | 장점 | 비용·위험 | 판단 |
| --- | --- | --- | --- |
| 이용약관이나 개인정보처리방침에만 출처를 기록 | 별도 화면이 필요 없다. | BGG의 공개 표시 요구를 충족하기 어렵고 개인정보 문서의 목적과도 맞지 않는다. | 제외 |
| 게임 카드·상세마다 모든 출처를 표시 | 게임 단위 출처를 바로 확인할 수 있다. | 반복 표기로 화면이 복잡해지고 필드별 혼합 출처를 짧게 설명하기 어렵다. | 제외 |
| 푸터에 BGG만 한 줄로 표시 | 구현이 단순하고 BGG 출처가 보인다. | 국내 출처와 팀의 직접 작성·검수·경험을 누락해 전체 데이터의 출처를 부정확하게 표현한다. | 제외 |
| 전역 푸터에 핵심 표기와 링크를 두고 별도 출처 페이지에서 상세 공개 | 모든 화면에서 출처를 발견할 수 있고 상세 정보는 한 곳에서 관리할 수 있다. | 푸터와 출처 페이지가 manifest의 변경을 계속 따라가야 한다. | 선택 |

## 결정

현재 P0 2,000개 게임 카탈로그를 서비스하는 동안 서비스의 모든 공개 화면에 공통 푸터를 둔다. 게임 카탈로그가 노출되지 않는 화면도 포함한다. 푸터에는 다음 요소를 제공한다.

- BoardGameGeek로 연결되는 읽을 수 있는 크기의 `Powered by BGG` 로고
- 게임 정보가 BGG, 국내 보드게임 자료와 Albam Mate 팀의 직접 작성·검수 및 플레이 경험을 바탕으로 구성됐다는 요약
- `데이터 출처`, `이용약관`, `개인정보처리방침` 링크. 각 페이지를 공개한 시점에 해당 링크를 추가하고, 아직 없는 페이지의 링크는 노출하지 않는다. 로고와 출처 요약은 첫 적용부터 함께 제공한다.

`데이터 출처` 페이지는 실제 승인·사용된 출처만 공개하며 다음 내용을 포함한다.

- 출처명과 원문 링크, 제공한 필드 범주, 확인 또는 취득 시점
- 외부 원천값, 팀이 외부 값을 선택·대조한 검수값, 팀이 직접 작성하거나 플레이 경험으로 판단한 값을 구분한 설명
- 표시명·별칭 등 팀 작성값의 작성 기준과 최종 검수 주체. BGG 원문 데이터에는 승인 범위 밖의 번역·변형을 가하지 않으며, 국내 자료에 정규화·요약을 적용한 경우 그 처리와 근거를 밝힌다.
- 출처별 이용 범위와 별도 표시 요구, 마지막 갱신일

팀 기여는 `팀 검수`와 `팀 직접 작성·경험`으로 구분한다. 외부 사실을 검수했다는 이유만으로 팀이 독립 작성한 값이라고 표시하지 않는다. 개인 기여를 공개할 때는 본인이 공개에 동의한 표시명만 사용한다.

공개 출처 페이지는 내부 provenance를 대체하지 않는다. 게임별·필드별 원문 위치, 매핑, 체크섬과 검수 상태는 source manifest와 입력 검수 기록에 계속 보존한다. 공개 페이지는 이 기록에서 공개 가능한 출처와 작성 기준을 사용하며 Private 브레인 경로나 비공개 근거를 노출하지 않는다.

이용약관에는 제3자 콘텐츠의 권리와 서비스 책임 범위를, 개인정보처리방침에는 개인정보 처리 사항만 기록한다. 출처별 조건이 카드·상세 같은 더 가까운 위치의 표기를 요구하면 해당 요구를 우선하며 전역 푸터만으로 대체하지 않는다.

현재 `image_url`은 허용된 외부 URL을 직접 참조한다. 이미지 다운로드·변환·S3 재호스팅은 이 결정에 포함하지 않고 기존 보류 상태를 유지한다.

## 결과

- 얻는 것: BGG 요구사항을 눈에 보이는 위치에서 충족하고, 외부 출처와 Albam Mate 팀의 기여를 부정확하게 한쪽으로 합치지 않으면서 사용자가 상세 근거를 확인할 수 있다.
- 감수할 비용·위험: 출처와 이용 조건이 바뀔 때 푸터·공개 출처 페이지·내부 manifest의 정합성을 함께 관리해야 한다. 공식 로고 자산과 링크의 접근성도 지속적으로 확인해야 한다.
- 후속 작업: 팀 승인 뒤 전역 푸터와 공개 출처 페이지 구현을 별도 기능 이슈로 만들고, 현재 2,000개 manifest의 필드별 출처와 공개 가능 범위를 다시 검수한다.

## 보류 및 재검토

- 지금 하지 않는 것: 2,000개 밖의 카탈로그 확장, 이미지 S3 재호스팅, 모든 카드·상세의 일괄 출처 표기, 이용약관·개인정보처리방침 본문 작성
- 보류 이유: 이번 결정은 현재 카탈로그의 공개 출처 표시 위치와 정보 구조만 확정한다.
- 다시 검토할 조건: 새 출처 유형을 추가할 때, 출처가 게임별 근접 표기를 요구할 때, BGG 이용 조건이나 서비스의 상업적 이용 여부가 바뀔 때, 이미지 재호스팅을 다시 검토할 때
