# 2차 관점 리뷰

같은 변경을 이미 한 번 리뷰한 뒤 다른 관점의 확인을 요청받았을 때만 일반 리뷰에 이 절을 더한다. 사용자가 1차 리뷰를 언급하지 않으면 일반 리뷰로 처리하고 없는 1차 결과를 찾아다니지 않는다.

- 1차 리뷰 결과를 reviewer 프롬프트에 넣지 않는다. 같은 결론을 복창하게 만들면 2차 리뷰의 의미가 없다. 1차 결과는 오케스트레이터가 관점 선택과 최종 대조에만 쓴다.
- 1차가 다룬 관점을 확인할 수 있으면 동점 후보 중 1차가 보지 않은 관점을 먼저 올린다. 사용자가 같은 관점의 재확인을 명시하면 그대로 실행한다.
- 1차 결과와 상충하는 결론을 감추지 않는다. `review-code-judge`로 재확인한 뒤 제목 뒤에 `(1차와 상충)`을 붙이고 문제점 절에 어느 쪽이 왜 맞는지 남긴다. 같은 제목을 inline comment와 요약의 `주요 지적`에 똑같이 써야 payload 검증을 통과한다.
- 1차 리뷰가 이미 게시됐을 수 있으므로 기본은 텍스트 보고다. 게시 모드에서는 `변경 요약` 절에 어떤 관점으로 다시 봤는지 한 줄을 덧붙인다. 판정 줄과 심각도 줄의 고정 형식은 바꾸지 않는다.
- 이 절은 관점 선택과 보고만 바꾼다. 범위 고정, 기계 출력 계약, 게시 전 payload 검증은 일반 리뷰와 같다.
