# 사용자 출력 표시 계약

검증된 일반 리뷰 결과만 아래 의미와 집계로 표시한다.

## 심각도

| | 레벨 | 의미 |
| --- | --- | --- |
| 🔴 | `critical` | 즉시 악용 가능한 취약점, 데이터 손상, 크래시, 핵심 요구사항 차단 |
| 🟠 | `major` | 머지 전 수정이 필요한 실질 버그 또는 설계 결함 |
| 🟡 | `minor` | 개선 권장이나 차단하지 않는 문제 |
| ⚪ | `nit` | 취향 또는 사소한 제안 |

## Finding

각 Finding에는 레벨과 제목, 정확한 `file:line`, 실패 조건·영향·계약 근거, 실행 가능한 수정 방향을 담는다. GitHub inline comment에서는 앵커가 위치를 대신할 수 있다.

~~~text
🟠 major | 만료된 토큰을 다시 허용함
위치: src/AuthService.java:42
문제: 만료 검사가 없어 탈취된 토큰으로 세션을 만들 수 있다.
수정: 세션 생성 전에 만료 시각을 검증하고 거부 경로를 테스트한다.
~~~

## 전체 판정

- 미검토 범위가 있으면 `Incomplete`, 그렇지 않고 critical이 있으면 `Blocked`, major가 있으면 `Changes Requested`, 완료됐고 critical·major가 없으면 `Approve`다.
- 심각도별 개수, 변경 요약, critical·major 핵심 지적과 다음 액션을 한 번 보고한다. minor·nit은 판정을 막지 않는다.
- 확인된 장점은 유용할 때만 덧붙이고 채우기 위한 칭찬은 만들지 않는다.
